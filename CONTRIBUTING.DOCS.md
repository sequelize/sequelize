# Documentation

The sequelize documentation is written in a combination of markdown (articles and example based documentation) and [JSDoc](http://usejsdoc.org) (API reference generated from source code comments).

All documentation is located in the `docs` folder. This fork does not build or publish a documentation site — the markdown is read as-is, and the JSDoc comments are read in the source.
